How it works

From repository to running app in three steps.

The extension stays out of your way until you need it — then deployment is a single click.

01

Open any repository

Browse to a GitHub repo root — github.com/owner/repo. The button appears in the header next to Watch and Star.

02

Click Deploy on Sealos

A new tab opens Sealos with the repository already attached. Sign in once and Desktop handles region and workspace.

03

Sealos ships it

Sealos runs the GitHub import and the AI deploy runner — no config files, no Dockerfile. Turn on auto-deploy in settings to skip the review step.

Install

Two minutes, no store required.

The extension is distributed as a ZIP while it's in early access. Load it unpacked and you're done.

1 · Download & unzip

  1. Download sealos-deploy-chrome-extension.zip below.
  2. Unzip it anywhere — you'll get a folder with manifest.json inside.

2 · Load into Chrome

  1. Open chrome://extensions and enable Developer mode (top right).
  2. Click Load unpacked and select the unzipped folder.
  3. Open any GitHub repository — the button is there.
